# My_tochka_opory_bot

# Точка опоры

Telegram-бот для бережной самоподдержки и прохождения внутренних состояний через последовательные вопросы.

Бот не принимает решения за человека, не ставит диагнозы и не заменяет медицинскую, психологическую или экстренную помощь.

## Первая версия

Доступны пять сценариев:

- 😰 Справиться с тревогой
- 🤔 Принять решение
- 💪 Перестать себя ругать
- 🎯 Определить следующий маленький шаг
- ❤️ Поддержать себя

## Технологии

- Node.js
- Telegraf
- PostgreSQL
- Railway
- GitHub

## Команды

- `/start` — открыть бота
- `/menu` — выбрать состояние
- `/cancel` — завершить текущий разговор
- `/scenarios` — увидеть доступные сценарии
- `/ping` — проверить бота и соединение с PostgreSQL

## Переменные Railway

В сервисе бота должны быть определены:

- `BOT_TOKEN`
- `DATABASE_URL`
- `NODE_ENV`
- `ADMIN_ID`

`BOT_TOKEN` выдаёт BotFather.

`DATABASE_URL` должна ссылаться на PostgreSQL-сервис Railway.

Для `NODE_ENV` используется значение `production`.

`ADMIN_ID` содержит числовой Telegram ID администратора.
